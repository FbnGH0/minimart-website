# Great Luck Minimart

Website for **Great Luck Myanmar Minimart**, a neighbourhood minimart in Toa Payoh, Singapore.

🌐 **Live site:** https://greatluckminimart.xyz

## Features

- **Home page:** shop info, opening hours, Google Map, and links to TikTok and Facebook
- **Products page:** products grouped into categories, each with a photo, description and price
- **Admin panel:** the shop owner logs in to update products, categories, opening hours, the map and social links, with no coding needed
- **Language picker:** translates the site into Burmese, Chinese, Malay or Tamil

## Built with

- HTML, CSS and JavaScript
- [Supabase](https://supabase.com) for the database, admin login and photo storage
- GitHub Pages for hosting, with a custom domain
